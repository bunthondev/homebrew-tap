# Homebrew tap for DeepClean

```sh
brew install --cask bunthondev/tap/deepclean
```

DeepClean is not notarized by Apple, so macOS blocks the first launch. Either install with
`--no-quarantine`, or run `xattr -d com.apple.quarantine /Applications/DeepClean.app` once after installing.

Project: https://github.com/bunthondev/deep-clean
